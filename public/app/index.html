How to install

  1. Tap Download and open the file when it finishes.
  2. If Android asks, allow your browser to install unknown apps. The app isn't on the Play Store yet, so this step is needed.
  3. Tap Install. You only need to do this once: the app will tell you when a new version is out.

Already have it? Install the new version over the old one, and your bookmarks and reading progress are kept. If Android says the app "conflicts with an existing package", you have the very first version (1.0). Uninstall that one once, then install this one.
