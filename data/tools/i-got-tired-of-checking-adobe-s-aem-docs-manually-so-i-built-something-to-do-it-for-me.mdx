Adobe updates AEM Cloud Service documentation constantly, and there's no changelog for it. A workflow step changes, a whole page gets rewritten, and you find out weeks later when someone mentions it in a call and you're staring blankly.

I told myself I'd check the AEM docs every week. Didn't happen. Not once. So I built a bot that checks for me.

Every day it scans Adobe's AEM Cloud Service documentation on Experience League — Sites docs, developer docs, implementation guides, all of it — and flags what actually changed. Not a diff of the HTML. An actual summary of what's different, in plain language, with a link if you want to read the source.

**Get AEM documentation alerts**

Two ways to subscribe:

- Telegram: [t.me/aem_docs_monitor_bot](https://t.me/aem_docs_monitor_bot) — message `/subscribe`
- WhatsApp: [join the community](https://chat.whatsapp.com/DzRl9nNC3RY9s9ktvzFbYA)

No account, no signup form. Just subscribe and you start getting daily scan results.

**What the alerts actually look like**

Telegram:

```
Scan complete — 2026-09-15 14:25 IST
Checked: 356 | Updated: 0 | Added: 1 | Removed: 0 | Failed: 0
Added:
  - https://experienceleague.adobe.com/en/docs/experience-manager-cloud-service/content/implementing/developing/opentelemetry-apm-integration

💡 Have feedback or questions? Send /feedback with your comments
```

WhatsApp:

```
Scan complete — 2026-09-15 14:25 IST
Checked: 356 | Updated: 0 | Added: 1 | Removed: 0 | Failed: 0
Added:
  - https://experienceleague.adobe.com/en/docs/experience-manager-cloud-service/content/implementing/developing/opentelemetry-apm-integration
```

If nothing changed in the AEM docs that day, you get nothing. No daily "all clear" message, no filler. I built this to kill noise, not add to it.
