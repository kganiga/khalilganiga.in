If you work with AEM Cloud Service, you know the drill. Adobe updates their documentation constantly. A new note here, a changed workflow step there, and sometimes a whole section gets rewritten and you find out three weeks later when someone in a meeting mentions something you've never seen.

I kept meaning to check the docs regularly. I never did. So I built a bot that does it instead.

It goes through Adobe's AEM Cloud Service documentation every day (Sites docs, developer and implementation docs, all of it) and tells me when a page's content actually changes. Not "something on this page is different," but what changed, in plain English, with a link to go read it yourself if you want the full picture.

**How to get updates**

Two ways, take your pick:

- Telegram bot: [t.me/aem\_docs\_monitor\_bot](https://t.me/aem_docs_monitor_bot). Message it `/subscribe` and you're in.  
    OR
- WhatsApp: [join the community](https://chat.whatsapp.com/DzRl9nNC3RY9s9ktvzFbYA)

That's it. No sign-up form, no account, nothing to configure.

**No spam.**

You'll only hear from this when Adobe actually changes something. If nothing changed that day, you won't get a message. I built this because I was annoyed by noise, not to create more of it.
